# Mini-Game Design Sheet: Q3 — Information Integration
**World:** The Hidden Gallery (`W5`)  
**Target Parameter:** `curiosity`  
**Behavioral Facet:** `knowledge_synthesis`  

---

## 1. Target Parameter & Behavioral Facet
- **Parameter Key:** `curiosity`
- **Facet:** `knowledge_synthesis`
- **Definition Reference:** Bound to authoritative definition in `config/parameters.json` for `curiosity`.

## 2. Nearest Researched Construct & Honest Match Note
- **Nearest Construct:** Spontaneous Cross-Domain Information Synthesis
- **Honesty Note:** Examines whether optional insights gathered in prior exploration are spontaneously utilized to contextualize a later exhibit.

## 3. Task Description & Trial Structure
- **Description:** A final archival curation challenge presents a contextual puzzle that is readily solved if optional alcove clues were read, but also solvable through deduction.
- **Trial Structure:** 2 thematic synthesis questions.

## 4. Nuisance Demands & Sibling Differentiation
- **Nuisance Demands:** Memory and comprehension; differentiates superficial browsing from cognitive processing.

## 5. Control / Decoy Conditions
- **Controls:** Baseline questions requiring only immediate stimulus information.

## 6. Raw Events Logged
- `synthesis_presented`
- `cross_reference_accessed`
- `synthesis_option_selected`

## 7. Extracted Behavioral Features
### Feature: `integrated_insight_utilization`
- **Formula:** count(synthesis solutions referencing optional clues) / total_synthesis_items
- **Units:** ratio
- **Direction of Interpretation:** Shows functional utility derived from spontaneous epistemic curiosity.
- **Construct Distinction (Why not click count):** Qualitative solution matching.



## 8. Data Sufficiency (`min_observations`)
- **Minimum Observations for `USABLE` Status:** `2`
- **Expected Observations:** `2`

## 9. Time Ceiling (`ceiling_ms`) & Censoring
- **Ceiling:** `30000 ms`
- **Behavior on Ceiling:** Task gracefully concludes; logged with `stop_reason: "ceiling"`; observations are marked right-censored.

## 10. Validity Rules (`INVALID` Criteria)
- **Invalidation Condition:** No response submitted.

## 11. Accessibility Alternative & Feature Exclusion
- **Interaction Alternative:** Accessible form choices with high contrast options.

## 12. Insufficient Evidence Manifestation
- **Insufficient Condition:** Synthesis skipped. Result marked `INSUFFICIENT` (never `LOW`).

## 13. Proposed Elements
- **PROPOSED (needs owner approval):** All heuristic features and thresholds are uncalibrated (`null` thresholds in `config/feature_bands.json`) pending empirical normative volunteer data.
