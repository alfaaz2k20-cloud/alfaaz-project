# Mini-Game Design Sheet: E3 — Changing Conditions
**World:** The Shifting Grid (`W4`)  
**Target Parameter:** `emotional_agility`  
**Behavioral Facet:** `strategy_adaptation`  

---

## 1. Target Parameter & Behavioral Facet
- **Parameter Key:** `emotional_agility`
- **Facet:** `strategy_adaptation`
- **Definition Reference:** Bound to authoritative definition in `config/parameters.json` for `emotional_agility`.

## 2. Nearest Researched Construct & Honest Match Note
- **Nearest Construct:** Strategy Modification under Constraint Modulation
- **Honesty Note:** Evaluates intentional strategy shift when time budget or grid density dynamically changes.

## 3. Task Description & Trial Structure
- **Description:** Grid configuration transforms from open layout to constrained labyrinth, requiring transition from broad scanning to sequential pathing.
- **Trial Structure:** 4 phases with progressive density changes.

## 4. Nuisance Demands & Sibling Differentiation
- **Nuisance Demands:** Spatial navigation; differentiated from E1 (rules) and E2 (disruptions).

## 5. Control / Decoy Conditions
- **Controls:** Phase with identical density to establish baseline approach.

## 6. Raw Events Logged
- `phase_start`
- `density_modified`
- `path_node_selected`
- `phase_complete`

## 7. Extracted Behavioral Features
### Feature: `strategy_shift_efficiency`
- **Formula:** path_efficiency_in_constrained_phase / path_efficiency_in_open_phase
- **Units:** ratio
- **Direction of Interpretation:** Capacity to shift behavioral mode in response to altered environmental constraints.
- **Construct Distinction (Why not click count):** Algorithmic path efficiency ratio.



## 8. Data Sufficiency (`min_observations`)
- **Minimum Observations for `USABLE` Status:** `3`
- **Expected Observations:** `4`

## 9. Time Ceiling (`ceiling_ms`) & Censoring
- **Ceiling:** `35000 ms`
- **Behavior on Ceiling:** Task gracefully concludes; logged with `stop_reason: "ceiling"`; observations are marked right-censored.

## 10. Validity Rules (`INVALID` Criteria)
- **Invalidation Condition:** No path completed.

## 11. Accessibility Alternative & Feature Exclusion
- **Interaction Alternative:** Step-by-step directional grid navigation via arrow keys.

## 12. Insufficient Evidence Manifestation
- **Insufficient Condition:** Fewer than 3 phases completed. Result marked `INSUFFICIENT` (never `LOW`).

## 13. Proposed Elements
- **PROPOSED (needs owner approval):** All heuristic features and thresholds are uncalibrated (`null` thresholds in `config/feature_bands.json`) pending empirical normative volunteer data.
